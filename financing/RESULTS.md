## T1b and the weak-evidence rule

T1b passed. The sealed file says what that is worth, and it is quoted here
rather than summarised, because the whole point of fixing it in advance was
that it would still be there when the result arrived:

> **For 2010-2015 starts a pass is weak evidence and a fail is strong
> evidence, because the benchmark substitution favours a pass.**

Pre-2020 mortgages were priced off SIBOR, which ran above SORA. Measuring
the break-even spread over SORA therefore overstates the SIBOR-equivalent
margin for exactly the cohorts T1b is about. The pass is consistent with
the claim; it is not strong evidence for it, and this sentence travels with
the headline number wherever it is published.
